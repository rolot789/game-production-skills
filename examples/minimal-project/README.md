# Minimal Project

This is a skeleton showing where each pipeline artifact belongs.

Start with:

```text
spec/
├── GameSpec.md
└── game-spec.yaml

art/
├── ArtStyle.md
├── art-style.yaml
└── style-anchor-manifest.yaml
```

Then the asset pipeline fills:

```text
assets/
generation/
normalized/
qc/
runtime-validation/
```
